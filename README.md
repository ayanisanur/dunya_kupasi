# Dünya Kupası 2026 - FOTOMAÇ

Bu proje, Dünya Kupası 2026 için hazırlanan statik bir haber ve maç takvimi arayüzüdür. HTML, JavaScript ve Tailwind CSS kullanılarak oluşturulmuştur.

## Özellikler

- Futbol haberleri ve video galerisi görünümü
- Yaklaşan maç listesi
- Grup tablosu ve maç detay bölümleri
- Mobil ve masaüstü uyumlu responsive tasarım
- Dinamik veri kartları ve slayt yapısı

## Kurulum

1. Proje klasörüne girin:
   ```bash
   cd dunya_kupasi
   ```

2. Bağımlılıkları kurun:
   ```bash
   npm install
   ```

3. Geliştirme sunucusunu başlatın:
   ```bash
   npm run dev
   ```

## Proje Yapısı

```text
├── index.html
├── index.js
├── package.json
├── tailwind.config.js
├── src/
│   └── input.css
└── dist/
    └── output.css
```

## Notlar

- Proje statik bir frontend uygulamasıdır.
- Yerel geliştirme için `npm run dev` komutunu kullanabilirsiniz.
- `dist/output.css` dosyası Tailwind CSS çıktısını içerir.
